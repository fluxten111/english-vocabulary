# 词间 · 英语词汇学习 V0.1

状态：修复版，待用户验收。只处理 V0.1；后续版本保持锁定。

## 本次已修复

- 音频按会话、词、阶段和播放器绑定；重播先停止旧播放，退出解除回调，旧音频不得串写新词记录。
- 备份导入前验证学习内容与准备状态，损坏内容拒绝导入，保留现有记录。
- 保存词表成功后启动准备任务；前约 5 词优先，之后继续准备。后台只局部更新进度，不清空输入或打断录音。
- 单次请求 15 秒、最多重试一次；整轮 150 秒截止，迟到结果禁止写入。重复点击防重，刷新不重置原预算。
- 无服务配置、未确认用途、缺项、待核对、查询失败和超时分别显示；没有任务时不显示正在加载。
- 返回内容核对请求编号、词编号、规范词形、词条／词义、核对记录和内容摘要，不能只凭 checked 或非空 reviewId 进入学习。

## 当前未完成

没有真实词典密钥、没有确认的使用范围、没有已部署的查询后端，也没有已核对的正式内容。网站仍不能开始真实词汇学习；不能把超时处理修好等同于真实内容已经可用。

申请与设置方法见 [接通词典步骤](接通词典步骤.md)。

## 检查与发布

Node.js 22+：

```sh
node --test *.test.mjs
```

测试包含受控服务和音频对象，均为测试数据，未用于正式学习。真实词典、真实专业录音与完整真实学习流程仍需另外检查。

GitHub Pages 从 main 根目录提供静态网页。dictionary-worker.mjs 和 wrangler.toml 是另行部署的服务端代码，GitHub Pages 不会运行它们。密钥只能存在后端 Secret 中。

记录保存在每个设备的当前浏览器，不自动同步；请定期导出备份。原词表、历史和旧备份兼容；没有为了修复而清空数据。
