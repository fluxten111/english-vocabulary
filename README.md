# 词间 · 英语词汇学习网站 V0.1

状态：版面试作，尚未完成学习能力验收。只制作 V0.1，后续版本继续锁定。

## 当前界面

- 学习首页：当前词表、开始／继续学习、分组位置。
- 我的词表：全部／待学／已学，原词表保留，已学批次可手动再练。
- 添加词表：粘贴或上传，去重及无效项提示，确认后先保存。
- 专注练习区域：声音与意义 → 先说后听 → 拼写与用法 → 可选造句 → 默写。
- 备份与设置：浏览器本地保存，导出／导入预览及冲突检查。

## 当前限制

用户已选择 Merriam-Webster Learner’s Dictionary 美音；中文人工核对；Wikimedia Commons 图片逐张核对来源、许可和词义，缺图用英文情境。词典服务与内容准备尚未接通，目前正式学习内容为零。缺少可靠内容时保留学习位置，不能把空内容算成完成。

记录分别保存在各设备当前浏览器；打开同一网址不会自动同步。无痕模式、清除网站数据或设备损坏会丢失未备份记录，请定期导出。网页不含密钥，个人词表和学习记录不会上传仓库。

## 检查

安装 Node.js 22 或更高版本后，在仓库目录运行：

```sh
node --test core.test.mjs
```

14 项核心检查已在本机实际执行通过。测试材料仅用于验证代码，不是正式词典内容。

## 发布与回退

GitHub Pages 使用 main 分支根目录。修改前提交版本记录，修改后运行检查并查看电脑和手机界面。出问题时可在 Git 中恢复此前提交；不要清空浏览器记录来解决问题。
