接通词典需要这几步

  1. 到 韦氏开发者注册页注册应用；在 Request API Key (1) 下拉菜单中选择 Learners Dictionary（学习者词典，含录音）。

  5. 核对首批单词的具体词义、情境和来源，再进行真实录音及完整学习测试。
